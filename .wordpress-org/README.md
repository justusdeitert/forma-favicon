# WordPress.org Plugin Assets

Place WordPress.org directory assets in this folder.

## Required for plugin icon

- `icon-128x128.png`
- `icon-256x256.png`

## Optional banner images

- `banner-772x250.png`
- `banner-1544x500.png`

## Optional high resolution icon alternatives

- `icon-128x128.jpg`
- `icon-256x256.jpg`

## Notes

- Use PNG for best transparency support
- Keep icon artwork centered with some padding
- After adding files, push `main` and release a new tag so deployment uploads assets
